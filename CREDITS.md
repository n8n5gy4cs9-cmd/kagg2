# Credits & licence

Kagg2 re-implements gameplay logic and data ideas from two GPL projects (references kept in
`REFERENCE_tobe_DELETED/` until the maintainer says to delete it; T31 did not remove it):

- **Space Nerds In Space** — © Stephen M. Cameron and contributors, GPL-2.0-or-later
  (https://github.com/smcameron/space-nerds-in-space). Its art/audio are CC-licensed and are
  **not** used here.
- **Quake 2** game source — © 1997–2001 Id Software, Inc., GPL-2.0-or-later. No Quake 2 art,
  maps or sounds are used.

Because logic is derived from GPL code, **Kagg2 is licensed GPL-2.0-or-later**. A `LICENSE`
file with the GPL v2 text sits at the repository root (added in T31). Each ported function
carries a `// ref: <file>.c <fn>` comment.

All textures, meshes and sounds are generated by Kagg2's own code.

Third-party Rust crates: macroquad, glam, png and their dependencies. T31 audit: all 48 packages
offer a permissive licence (MIT, Apache-2.0, BSD-3-Clause, Zlib, 0BSD, Unlicense) that can be
combined with GPL-2.0-or-later; the table is in [LICENCES.md](LICENCES.md), regenerated by
`python3 tools/licence_check.py`, which also fails if a shipped file is byte-identical to a
reference file.
