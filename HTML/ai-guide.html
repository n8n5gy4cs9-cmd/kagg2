AI helper guide

Everything an AI coding agent needs to work in this repository without breaking it. Read this, then AGENTS.md, tasks.md and HANDOFF.md.

Orientation in one minute#

  • What: Kagg2, a Rust (edition 2024) game: a bridge simulator in space plus a first-person boarding game. Crate kagg2, version in Cargo.toml.
  • Where the work is: tasks.md lists Done and Undone tasks. Do the first undone task unless told otherwise. Details per task are in PLAN.md.
  • State of play: HANDOFF.md says what is done, what is next, what is unverified and how to resume.
  • Folder rules: ../AGENTS.md (Rust rules) is inherited; AGENTS.md here adds Kagg2 rules. The VoxlBit/NordCraft documentation rules do not apply.

Hard rules#

Definition of done (run before finishing)#

cargo check
cargo clippy --all-targets -- -D warnings
cargo test --release
cargo fmt
python3 tools/make_html.py      # only if docs changed
python3 tools/licence_check.py  # if dependencies, assets or licence files changed
cargo run --release --bin playtest 3   # if missions, balance.rs, the bots or boarding changed

Quote real command output as evidence. Max three repair attempts per failing check, then stop and report the blocker. After the task: move the line in tasks.md to Done, update HANDOFF.md and the design docs touched, bump the version (minor per task, patch per fix) and offer a one-line commit message vX.Y.Z: ....

Recipes#

Tune a mission#

Edit the numbers in the mission's static (sim/mission.rs): spawn offsets (player-frame, -z is ahead), class lists, beat times, the stage limit. Run cargo test --release --lib mission. Do not make objective text longer than 79 characters or captions longer than 99; tests enforce it.

Add a goal or a role#

Extend Goal / Role, handle it in goal_met / do_spawn, add a test. Decide whether the goal must wait for spawns (beats_done).

Add a setting#

Settings field, to_text, from_text, a row in settings_ui.rs (adjust FIXED_ROWS and the match arms), apply it in main.rs, extend the round-trip test in save.rs.

Add a keybinding#

See the developer guide: Bind variant, ALL length, name, default, replace the literal key in space_scene.rs.

Change a balance number#

Edit it in src/balance.rs (or the mission data), run cargo run --release --bin playtest 4 and ... playtest 12 boarding before and after, and report both tables. Do not assert exact win rates in tests; assert shapes. A change that makes a mission unwinnable for the bot shows up as STUCK or a failure reason in the table.

Add a Command#

Variant in sim/command.rs, handler, UI; then net/wire.rs (put_command/get_command, and the round-trip test list) and net::station_of. The compiler flags the missing match arms.

Add a script goal#

See the developer guide section "Mission scripts"; update the format table in the manual too.

Find where an event is handled#

Events are defined in sim/event.rs; the scene reacts in SpaceScene::on_event; missions only see Destroyed directly (plus world state polling).

Pitfalls seen in this repo#

  • The bots measure what they can: they cannot judge fun. Do not claim a feel or sound verification from a bot run.
  • Long runs (playtest 12 boarding takes a few minutes): start them in the background and read the output file.
  • macOS sed -i needs an argument; use perl -pi -e or Python for scripted edits. In zsh, unquoted globs such as --include=*.rs fail: quote them.
  • Edition 2024 reserves gen; let-chains are in use (clippy asks for them); prefer is_multiple_of over % n == 0.
  • macroquad pixel-font text should use integer scales; the HUD derives them from ui_scale.
  • The sim is stepped from SpaceScene::update; discrete commands wait in a queue until a step runs, held commands keep only their latest value.
  • Entity labels are &'static str; mission spawns override labels with static strings, and goals match by prefix (starts_with).
  • Run the game in --release; debug is slow. Screenshots: ./run.sh shot out.png --frames N. A real mission flow needs a human at the keyboard.
  • Use a scratch KAGG2_HOME (for example under target/) when running the game from scripts so your own settings and saves are not touched.

Verification checklist for reviewers#

  • Clippy clean and all tests pass; cargo fmt applied.
  • No macroquad in sim/ or board/; no wall clock; no new unwraps.
  • Docs, tasks.md, HANDOFF.md and the version agree.
  • Anything not verified (sound, mouse feel, balance) is stated in HANDOFF.md.

Prompt snippet for a new agent session#

Read HANDOFF.md, tasks.md and AGENTS.md in Kagga2/. Do the first undone task.
Follow the Kagg2 rules (headless sim, determinism, generated assets, no unwrap).
Finish with cargo check, clippy -D warnings, cargo test --release, cargo fmt,
update tasks.md/HANDOFF.md/docs, bump the version and offer a commit message.
